查询接口改成参数绑定后，排序字段一传就报错，只好又把字符串拼了回去：值直接拼进语句，引号里的内容被当成语法；占位符按值格式化，本质上还是字符串拼接；标识符不做白名单，任意列名可注入；标识符引用用反引号包裹但不转义内部反引号；集合参数展开用逗号拼接值，而不是多个占位符；行数上限不校验，可以一次拉全表；插入计划不校验列名与行键数量，列错位；策略校验不检查是否允许拼接；批量构造复用参数元组，后一个计划带上一个计划的值；排序方向参数不做枚举校验，任意字符串进入语句。query/binder.py 是核心，tests/unit/test_binder.py 15个红，边界目录另有 5 条。要修的是：按上面的顺序把 10 个缺陷逐个修掉。
